# cheat-sheets - Cheat Sheets Launcher

A cross-platform desktop application for Windows, Linux, and macOS that provides instant access to application cheat sheets.

With a global keyboard shortcut, users can open a searchable overlay, find an application, and quickly view its most important cheat sheets in a dedicated window.

## Overview

Cheat Sheets Launcher is designed to help users access essential commands, shortcuts, and references without interrupting their workflow.

Instead of searching the web or opening documentation manually, users can press a shortcut, search for a tool, and immediately open a focused cheat sheet window.

## Features

- Cross-platform support for Windows, Linux, and macOS.
- Global keyboard shortcut to open the launcher.
- Searchable overlay for quickly finding applications.
- Dedicated cheat sheet window for each selected application.
- Fast access to the most important shortcuts, commands, and references.
- Clean and lightweight experience focused on productivity.
- Extensible structure for adding new applications and cheat sheets.

## How It Works

1. The user presses a predefined global shortcut.
2. The application opens a search overlay on top of the current screen.
3. The user types the name of an application.
4. The user selects one of the search results.
5. The application opens a window displaying the main cheat sheets for that app.

## Why This Project

Modern tools are powerful, but many of them have large sets of shortcuts and commands that are hard to memorize.

Cheat Sheets Launcher aims to solve this by making the most useful references available in a few keystrokes, exactly when they are needed.
